# Web HSK update policy

- Curriculum updates are additive by default. Adding HSK 2 or any new level must retain HSK 1 and all other existing levels, lessons, vocabulary, grammar, audio, images and attached documents.
- Preserve account data, progress, notes, course IDs and lesson/card keys. Do not delete data, reset D1, or replace an existing curriculum with a new level as part of an update.
- Merge partial course imports by lesson number and retain omitted lessons and items. Re-importing the same additions must not duplicate them. Corrections may refresh matching fields while retaining unrelated existing content.
- Keep the current primary textbook attachment. A different incoming PDF is an additional selectable document.
- An incomplete or older device catalog must not generate course/lesson deletion records during synchronization.
- Remove existing curriculum content only when the user explicitly requests the specific removal.
- Run the additive update regression checks before publishing content/import/sync changes. Keep original HSK 1 data and assets unchanged when updating HSK 2.
